# 📋 دستورالعمل اعمال آپدیت‌ها — ملکینو (نسخهٔ کامل، ۳ مرحله)

این zip شامل **۴۱ فایلِ تغییرکرده/جدید** از branch `security-hardening` است
(۳۸ فایل ویرایش‌شده + ۳ فایل جدید: `.htaccess`، `admin-logout.php`، `csrf-shim.php`).

مجموعهٔ تغییرات شامل این سه مرحله است:

| مرحله | خلاصه |
|---|---|
| ۱ — امنیت | محافظت CSRF روی تمام فرم‌ها و API، خروج واقعی ادمین، سخت‌کردن کوکی نشست و هدرهای امنیتی، تک‌بار کردن توکن لاگین، حذف `config.secrets.php` از گیت |
| ۲ — پنل/تصاویر | آپلود تصویر بلافاصله در دیتابیس ثبت می‌شود (روی کارت نمایش داده می‌شود)، انتخاب چندتایی و حذف گروهی تصاویر در ویرایش آگهی |
| ۳ — رفع باگ دکمهٔ ذخیره | دکمهٔ «ذخیره تغییرات» در ویرایش آگهی روی موبایل (و تا حدی دسکتاپ) بریده/نامرئی بود → با ساختار flex اصلاح شد؛ فایل `admin-ads-modals.php` که در آپلود اولیه نصفه مانده بود کامل شد؛ باگ `escapeHtml` تب کاربران برطرف شد |
| ۴ — رفع باگ شمارنده و کش | شمارندهٔ «N تصویر برای انتشار انتخاب شده» بعد از تیک‌زدن/آپلود عوض نمی‌شد → درست شد؛ فایل‌های JS پنل حالا با پارامتر نسخه (`?v=…`) لود می‌شوند تا گوشی/هاست دیگر هرگز JS کهنه اجرا نکند (علت اصلی رفتار عجیب قبلی همین بود)؛ ذخیرهٔ ویرایش فقط همان یک آگهی را ارسال می‌کند (حجم کم → قابل‌اتکا روی هاست اشتراکی)؛ هر خطای JS پنل به‌جای بی‌پاسخ ماندن دکمه، پیام قابل‌فهم نشان می‌دهد |
| ۵ — مقایسه | دکمهٔ ⚖️ در صفحهٔ جزئیات ملک برای کاربرِ وارد‌نشده خطا می‌داد (API قدیمی بدون پشتیبانی مهمان) → حالا مهمان‌ها هم می‌توانند مقایسه کنند و به‌محض ورود، لیستشان به حساب منتقل می‌شود (بدون تکرار)؛ بخش مقایسه در پروفایل داخل یک کارت سفید هم‌شکل بقیهٔ کارت‌ها قرار گرفت؛ وضعیت «در مقایسه» دکمه و شمارندهٔ حباب حالا از سرور رندر می‌شوند |
| ۶ — صفحه مقایسه | مقایسه حالا **صفحهٔ مستقل** دارد (`compare-page.php`: دسته‌ها، تغییر نام، جابه‌جایی/حذف، جدول امتیاز از ۱۰۰)؛ در پروفایل به‌جای بخش تودرتو، یک **کارت منو** با نشانِ تعداد گذاشتیم که با یک لمس به همان صفحه می‌رود؛ دکمهٔ ⚖️ در جزئیات ملک از روی عکس گالری به یک **دکمهٔ بزرگ برچسب‌دار** زیر اطلاعات ملک منتقل شد («افزودن به مقایسه» / «در مقایسه»)؛ دکمهٔ « بروزرسانی پیشنهادها» از پروفایل به **صفحهٔ فایل‌های مناسب من** منتقل شد (جایی که نتیجه‌اش دیده می‌شود) |
| ۷ — اصلاحات روی سایت واقعی | کارت «مقایسه ملک‌ها» در پروفایل حالا دقیقاً هم‌شکل کارت «فایل‌های مناسب من» است (کارت آماری با عدد و آیکون، نه ردیف منو)؛ خطای ۴۰۴ صفحهٔ مقایسه رفع شد — **زیپ این نسخه کل فایل‌های سایت را دارد** (نه فقط فایل‌های تغییریافته)، پس `compare-page.php` حتماً روی هاست می‌نشیند؛ فیلد «شماره موبایل» در پنجرهٔ ویرایش حساب دیگر readonly نیست — کیبورد باز می‌شود و شمارهٔ جدید واقعاً در دیتابیس ذخیره می‌شود؛ حباب «⚖️ مقایسه» بالاتر از نوار پایین قرار گرفت و دیگر روی تب «پروفایل» نمی‌افتد؛ دو ستون جاافتاده در اسکیمای نصب تازه (`settings.value_type/setting_group/updated_by_admin_id` و `amenities.sort_order`) اضافه شد — بدون آن‌ها صفحهٔ جزئیات ملک روی نصب تازه ۵۰۰ می‌گرفت |
| ۸ — کنترل روش‌های ورود | ادمین در تب «ربات و کانال» کارت جدید «🔐 روش‌های ورود کاربران» دارد: سه کلید برای **تلگرام / بله / پیامک (کد یک‌بارمصرف)**. روش غیرفعال در صفحهٔ ورود **اصلاً نمایش داده نمی‌شود** و اندپوینت سمت سرور هم ۴۰۳ برمی‌گرداند (غیرفعال‌سازی واقعی، نه ظاهری). ورود پیامکی که قبلاً با کد سخت‌کد غیرفعال بود، حالا کامل کار می‌کند: فرم شماره ← کد ۶ رقمی ← ورود (اولویت ارسال کد: ربات تلگرام/بله ← پنل پیامک ← نمایش موقت روی صفحه). گارد: حداقل یکی از سه روش باید فعال بماند. دو ستون/جدول جاافتادهٔ اسکیمای نصب تازه هم اضافه شد: `users.access_token` و جدول `otp_codes` |
| ۹ — تعمیر پنل ادمین + امکانات جدید | **فاصلهٔ خالی زیر تب‌ها و کندی پنل**: دو تکهٔ خرابِ HTML (چند `</div>` اضافه جا مانده از ویرایش‌های قدیمی در `admin-backup.php` و `admin-panel.php`) باعث می‌شد محتوای تب‌ها از کادر اصلی بیرون بیفتد و صفحه «خالی» دیده شود؛ ترمیم شد و حالا محتوا بلافاصله زیر تب‌هاست؛ به‌علاوه فشرده‌سازی gzip در `.htaccess` فعال شد (HTML پنل از ~۲۴۵KB به ~۴۰KB در انتقال می‌رسد). **لینکدین** کاملاً از تب تماس حذف شد. **اعلان‌ها**: نوار ابزار جدید با چک‌باکس روی هر اعلان، «انتخاب همه»، فیلتر نوع، «حذف انتخاب‌شده‌ها»، «حذف همهٔ یک نوع» و «حذف همه». **انتشار در کانال**: فیلد جدید «🌐 لینک آگهی در سایت» که ادمین روشن/خاموش می‌کند و لینک مستقیم همان آگهی به پیام اضافه می‌شود. **عیب‌یاب**: گروه جدید «سلامت قابلیت‌های جدید» با ۱۹ بررسی (نسخهٔ فایل‌های آپلودشده، فایل‌های جا ماندهٔ نصب، ستون‌ها/جداول جدید، یکدستی collation، روش‌های ورود، فیلد لینک). **دکمهٔ خروج پروفایل** که تابعش تعریف نشده بود حالا کار می‌کند. اسکیمای نصب تازه هم کامل شد: ستون‌های `notifications` (url/broadcast_id/request_id/ad_id/match_percent) و جدول `notification_broadcasts` |

## روش ۳ — نصب از داخل خود سرور (پیشنهادی، ضدِ آپلود ناقص)

چند بار آپلود مرورگری فایل‌های بزرگ را وسط راه برید و نسخه‌ی کهنه روی هاست ماند.
این روش کل بسته را **داخل هاست** باز می‌کند:

1. وارد پنل ادمین شو (لاگین ادمین).
2. از فایل‌منیجر هاست (InfinityFree) این دو فایل را در پوشه‌ی سایت بگذار:
   - `melkino-install.php`
   - `melkino-security-changes.zip`
3. آدرس `https://melkinoshahrood.ir/melkino-install.php` را باز کن →
   فهرست فایل‌های بازنویسی‌شده را می‌بینی (کانفیگ و رازها هرگز لمس نمی‌شوند).
   - اگر هاست افزونهٔ zip نداشته باشد، پیام می‌دهد که zip را با خود فایل‌منیجر
     extract کنی تا پوشهٔ `melkino-update/` ساخته شود؛ بعد همان آدرس را دوباره باز کن.
4. همین دو فایل (نصب‌کننده + zip/پوشه) را از هاست **حذف** کن.
5. یک بار `melkino-migrate.php` را با لاگین ادمین باز کن تا ساختار دیتابیس
   (جدول‌ها/ستون‌های جاافتاده + یکسان‌سازی collation) همگام شود؛ گزارش فارسی می‌دهد.

## 🗄 فایل دیتابیس (`melkino-database.sql`)

- فقط `CREATE TABLE IF NOT EXISTS` است؛ import روی دیتابیس فعلی **هیچ داده‌ای را پاک نمی‌کند**،
  فقط جدول‌های جاافتاده را می‌سازد.
- ستون‌های جاافتادهٔ جدول‌های *موجود* را `melkino-migrate.php` اضافه می‌کند (نه این sql).
- برای دیتابیس کاملاً تازه: اول این sql را import کن، بعد سایت را بالا بیاور.

## روش ۱ — آپلود دستی از وب‌سایت GitHub (ساده‌تر)

1. در GitHub به ریپازیتوری `melkino` برو.
2. روی **`Add file`** → **`Upload files`** کلیک کن.
3. **همه فایل‌های این zip** (پس از استخراج) را انتخاب و رها کن.
   - ⚠️ فایل‌ها را **در ریشه‌ی ریپازیتوری** بگذار (همان پوشه‌هایی که الان دارند،
     نه داخل پوشه‌ی جداگانه). چون در zip ساختار پوشه حفظ شده، اگر همه‌چیز درست
     باشد، جایگزین فایل‌های موجود می‌شوند.
   - ⚠️ دقت کن که آپلود **کامل** انجام شود؛ در آپلود قبلی فایل
     `admin-ads-modals.php` نصفه (قطع در میانهٔ یک تگ) ذخیره شده بود که باعث
     بخشی از مشکل مودال ویرایش بود. بعد از آپلود، اطمینان بگیر که فایل
     `admin-ads-modals.php` در GitHub تا انتهای `</div>` (پایان مودال ویرایش) کامل است.
4. پایین صفحه: عنوان commit بنویس `Security + admin panel fixes`
   و روی **`Commit changes`** بزن. (اختیاری: اول branch جدید بساز و بعد merge کن.)

## ⛔ بعد از آپلود: حذف config.secrets.php از ریپازیتوری

این فایل باید از **ریپازیتوری** حذف شود (فایل روی سرور دست‌نخورده می‌ماند):

- از وب: فایل `config.secrets.php` → آیکون سطل‌زباله → Commit deletion
- یا: `git rm config.secrets.php && git commit -m "untrack secrets" && git push`

> `.gitignore` از قبل این فایل را cover می‌کند؛ پس دیگر commit نمی‌شود.

## ⚠️ الزامی — بازنشانی رازها (مستقل از کد)

رازها **در تاریخچه‌ی git** مانده‌اند؛ آپدیت کد آن‌ها را پاک نمی‌کند:

1. رمز دیتابیس را در پنل InfinityFree عوض کن (و در `config.secrets.php` **سرور** آپدیت کن).
2. توکن تلگرام: `@BotFather` → `/revoke`.
3. توکن بله: پنل توسعه‌دهندگان بله.
4. ادمین واقعی را در جدول `admins` بساز (تب امنیت پنل) و
   `MELKINO_LEGACY_ADMIN_PASSWORD` را از `config.secrets.php` سرور حذف کن.
5. پاک‌سازی تاریخچه (اختیاری ولی توصیه‌شده، بعد از merge):
   `git filter-repo --invert-paths --path config.secrets.php` + `git push --force`

## 🔍 توضیح فنی رفع باگ دکمهٔ ذخیره (مرحلهٔ ۳)

**علت:** مودال ویرایش آگهی یک هدر («✏️ ویرایش آگهی» + دکمهٔ ✕) دارد و زیر آن
محتوای مودال می‌آید. روی موبایل قاب مودال `100dvh` و `overflow:hidden` است، ولی
ارتفاع محتوا به‌صورت مطلق `100dvh` (و در کد قبلی تا `90vh` + هدر) تعیین شده بود؛
یعنی مجموع «هدر + محتوا» از ارتفاع قاب بیشتر می‌شد و فوتر (دکمهٔ ذخیره) از پایین
بریده می‌شد — دقیقاً همان چیزی که دیده بودی.

**راه‌حل:** زنجیرهٔ flex: قاب مودال → `#adEditContent` → `.edit-pro-shell` هر سه
ستونی‌اند و هر کدام `flex:1 1 auto; min-height:0` می‌گیرند؛ یعنی ارتفاع از قاب
**محاسبه** می‌شود به‌جای مقدار مطلق. فقط ناحیهٔ فرم (`.edit-pro-body`) اسکرول
می‌شود و هدر و فوتر (دکمهٔ ذخیره) همیشه ثابت و قابل‌مشاهده می‌مانند.

- [ ] در ویرایش آگهی: تصویر آپلود کن بدون ذخیره → باید همان لحظه در لیست تصاویر (و روی کارت) دیده شود.
- [ ] تب «تصویر و انتشار»: چند تصویر تیک بزن → «حذف انتخاب‌شده‌ها» باید همه را پاک کند.

- [ ] **شمارندهٔ انتشار**: در تب «تصاویر و انتشار» تیک «انتشار» یک تصویر را بزن/بردار → عدد جلوی «تصویر برای انتشار انتخاب شده» همان لحظه عوض شود.
- [ ] بعد از آپلود تصویر جدید، شمارنده بدون ذخیره‌کردن زیاد شود.
- [ ] اگر جایی دکمه‌ای کار نکرد، حالا یک پیام خطای قابل‌خواندن ظاهر می‌شود؛ متن/اسکرین‌شاتش را نگه دار.
- [ ] **پنل ادمین**: باز کن → محتوا باید **بلافاصله زیر تب‌ها** باشد (نه فضای خالی)؛ تب «تماس» دیگر فیلد لینکدین ندارد.

- [ ] **لینک آگهی در انتشار**: تب «ربات و کانال» → بخش محتوای انتشار → چک‌باکس «🌐 لینک آگهی در سایت» را ببین؛ با «پیش‌نمایش» باید خط لینک آگهی در متن باشد؛ خاموشش کن و ذخیره کن → دیگر نباشد.
- [ ] **عیب‌یاب**: تب «عیب‌یاب» → «شروع تست» → گروه «۸. سلامت قابلیت‌های جدید» باید پر از ✅ باشد (به‌جز هشدارِ درستِ «فایل نصب را حذف کن» اگر هنوز هست).
- [ ] **خروج**: پروفایل ← دکمهٔ خروج ← باید بپرسد و خارج کند.
- [ ] **روش‌های ورود**: پنل ادمین ← تب «ربات و کانال» ← کارت «🔐 روش‌های ورود کاربران»؛ مثلاً بله را خاموش و پیامک را روشن کن و ذخیره کن → در `login.php` دکمه/لینک بله نباشد، فرم «ورود با شماره موبایل» باشد؛ هر سه را خاموش کن → پیام «حداقل یکی … فعال بماند» بگیرد.
- [ ] **ورود پیامکی**: شماره بزن → «دریافت کد یک‌بارمصرف» → کد را وارد کن → ورود موفق و انتقال به پروفایل. (اگر پنل پیامک تنظیم نشده باشد، کد موقتاً روی صفحه نشان داده می‌شود.)
- [ ] **کارت مقایسه در پروفایل**: باید هم‌شکل «فایل‌های مناسب من» باشد (آیکون ⚖️ + عدد) و با لمس به `compare-page.php` برود (بدون ۴۰۴).
- [ ] **ویرایش حساب**: پروفایل ← ویرایش نام ← روی «شماره موبایل» بزن → کیبورد عددی باز شود؛ شماره را عوض کن و ذخیره کن → بعد از بستن، دوباره باز کن و ببین شمارهٔ جدید مانده.
- [ ] **حباب مقایسه**: در صفحهٔ جزئیات ملک، حباب «⚖️ مقایسه» باید **بالای** نوار پایین باشد، نه روی تب «پروفایل».
- [ ] **مقایسه (بدون ورود)**: در مرورگر معمولی (بدون ورود با تلگرام) روی ⚖️ یک ملک بزن → باید «اضافه شد» ببینی و حباب «⚖️ مقایسه (۱)» ظاهر شود؛ بعد با تلگرام وارد شو → همان لیست در پروفایل ← کارت «مقایسه ملک‌ها» باشد.
- [ ] «خروج» ادمین: بعد از خروج، پنل باید دوباره رمز بخواهد.
- [ ] `X-Frame-Options` و `Set-Cookie: ... HttpOnly; SameSite=Lax` در Response Headers مرورگر دیده شود.
